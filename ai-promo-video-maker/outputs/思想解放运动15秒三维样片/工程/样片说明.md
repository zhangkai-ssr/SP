# 思想解放运动 · 15 秒三维样片

由 ai-promo-video-maker/template 创建。30 fps，1920×1080，450 帧。
全部角色、卡片、轨道和数学曲线为 Three.js 几何，中文为 React 投影叠层；动画只由帧号驱动。

## 复现

1. `npm ci`
2. 使用装有模板 requirements.txt 中音频/字体依赖的 Python，运行 `scripts/fonts.py` 和 `scripts/mix.py`。本机用工具目录的 `.venv/Scripts/python.exe`。
3. `node scripts/test-plan.mjs` 与 `npm run lint`。
4. `npx remotion render Promo out/思想解放运动_15秒三维样片.mp4 --gl=angle --concurrency=2 --video-bitrate=12M --codec=h264 --pixel-format=yuv420p --timeout=120000`
5. 当前 Remotion JPEG 渲染链生成 full-range BT.601 视频、AAC 总封装时长多 61 ms。交付时从原始混音重新封装并正确转换到有限范围 BT.709：

```powershell
ffmpeg -i out/思想解放运动_15秒三维样片.mp4 -i public/audio/mix.wav -map 0:v:0 -map 1:a:0 -vf "scale=in_range=pc:out_range=tv:out_color_matrix=bt709,format=yuv420p" -c:v libx264 -preset slow -b:v 14M -maxrate 18M -bufsize 28M -color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709 -c:a aac -b:a 192k -ar 48000 -t 15 -movflags +faststart out/思想解放运动_15秒三维样片_交付.mp4
```

6. 运行 `scripts/qa-sample.py`，检查实际 MP4 并提取六张审阅帧。

配乐为原创合成试听节奏带，无旁白。尚未制作 115 秒完整版，未做手机端实机播放验证。本工程不是成品网站，保留的 web/ 为模板附属入口。
