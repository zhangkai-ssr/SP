# 产品宣传视频制作器 · 工具自宣片

A 明亮产品发布会风格，45秒、16:9、1920×1080、30fps，字幕＋配乐，无旁白。没有配置 API Key，也没有调用生成类 API。

## 直接观看

下载 [宣传片 1080p.mp4](宣传片%201080p.mp4) 即可播放。GitHub 页面不能播放时，下载原始文件在本地打开。

## 从仓库恢复工程（Windows PowerShell）

先安装 Node.js 18+、Python 3.9+、FFmpeg（含 ffprobe），确认它们可用。进入本文件旁的 `工程/`，依次执行；命令失败时先解决报错再继续：

```powershell
Set-Location 工程
python -m venv .venv
$env:PATH = (Join-Path $PWD '.venv\Scripts') + ';' + $env:PATH
$env:PYTHONUTF8 = '1'
python -m pip install -r requirements.txt
npm.cmd ci
npx.cmd --no-install remotion browser ensure
python scripts/fonts.py
```

字体由 `fonts.json` 从本机字体生成，Windows 使用微软雅黑；仓库不分发系统字体文件。其他系统需要安装配置中列出的字体或改用自行获授权的字体。

配乐是 Michael Ramir C. 的 **Gimme that Groove!**（Mixkit，ID 872）。先阅读 [音乐许可](https://mixkit.co/license/#musicFree)，从 [来源页面](https://mixkit.co/free-stock-music/tag/funk/) 获取该曲，保存为 `工程/audio-src/original.mp3`；也可在确认许可后使用下面的来源地址：

```powershell
Invoke-WebRequest 'https://assets.mixkit.co/music/872/872.mp3' -OutFile audio-src/original.mp3
ffmpeg -v error -y -ss 5.0176 -i audio-src/original.mp3 -af atempo=1.0681 -t 45 -ar 48000 -b:a 256k audio-src/music.mp3
if ($LASTEXITCODE -ne 0) { throw '配乐处理失败' }
python scripts/mix.py
if ($LASTEXITCODE -ne 0) { throw '混音失败' }
```

原曲、处理后的独立配乐和混音不提交到 Git；成片已包含实际使用的音轨。源码沿用上游 MIT 许可；第三方音乐、系统字体、案例中的品牌标识仍按各自权利和许可使用。素材出处见 `素材来源.json` 和 `调研笔记.md`。

## 预览、修改和导出

```powershell
npm.cmd run dev -- --port=3098 --no-open
```

打开 http://localhost:3098/PromoPreview 。文案与镜头在 `src/scenes/Example.tsx`，时间线在 `src/timing.json`，配色在 `src/lib/theme.ts`。修改文案后重新运行 `python scripts/fonts.py`。

构建并预览同源网页版：

```powershell
npm.cmd run web:build
npx.cmd --no-install vite preview --config web/vite.config.ts --host 127.0.0.1 --port 18765 --strictPort
```

打开 http://127.0.0.1:18765/ 。构建产物位于 `工程/out/web/`，不提交到 Git。若端口已被占用，请换一个端口。

Windows 渲染1080p：

```powershell
python scripts/check_assets.py
npm.cmd run lint
python scripts/check_storyboard.py
New-Item -ItemType Directory -Path out -Force | Out-Null
npx.cmd --no-install remotion render Promo out/final-1080p.mp4 --concurrency=2 --crf=16 2>&1 | Tee-Object out/render.log
if ($LASTEXITCODE -ne 0) { throw '渲染失败' }
python scripts/check_video.py out/final-1080p.mp4 --scale 1
```

本示例保留上游脚本，其中 `render:1080`、`render:4k` 使用 bash；Windows 请用上述渲染方式。Python 脚本直接使用 `python`，避免 Windows 上 `python3` 命令未配置的问题。重新导出的成片默认保留在 `out/`，人工确认后再替换交付版。
