# 乘风入山海

原创横屏国风动态短片项目。参考视频只用于节奏与结构分析，本项目不复用其画面、角色、音轨或原句。

## 项目内容

- `参考视频分析.md`：参考片技术参数、镜头结构和改写边界。
- `Seedance2.5_创作执行稿.md`：真正动态版本的多模态素材映射、30 秒时间线和主提示词。
- `漫剧脚本.json`：无配音静态分镜预览配置，不是最终视频方案。
- `assets/manju/`：6 张 OpenAI ImageGen 原创插画。
- `bgm/ambient.wav`：程序化生成的原创氛围音乐副本。
- `work/`：临时过程区，不纳入 Git。
- `output/`：本地渲染过程输出，默认不纳入 Git。
- `素材来源与版权.md`：图像、音乐、文字和语音来源。
- `失败复盘.md`：记录第一版为什么不符合用户要求。

## 本地静态分镜预览

在本项目目录运行：

```powershell
python ..\存在主义项目\manju.py --script .\漫剧脚本.json --engine none --out .\output\乘风入山海_静态分镜预览.mp4
```

这条命令只用于检查镜头顺序和字幕，不是正式成片。最终版本必须按 `Seedance2.5_创作执行稿.md` 生成真实人物、载具、环境和镜头运动；明确禁止旁白、对白和 TTS。项目内 BGM 的 SHA-256 为 `6E1DEA1929134F6195E5E549AA2A42DD14D01C56FC5C35EC94CFA32375969B87`。
