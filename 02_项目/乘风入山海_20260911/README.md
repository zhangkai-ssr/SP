# 乘风入山海

原创横屏国风动画短片项目。参考视频只用于节奏与结构分析，本项目不复用其画面、角色、音轨或原句。

## 项目内容

- `参考视频分析.md`：参考片技术参数、镜头结构和改写边界。
- `漫剧脚本.json`：标题、旁白、镜头、运镜和音频配置。
- `assets/manju/`：6 张 OpenAI ImageGen 原创插画。
- `bgm/ambient.wav`：程序化生成的原创氛围音乐副本。
- `work/`：临时过程区，不纳入 Git。
- `output/`：本地渲染过程输出，默认不纳入 Git。
- `素材来源与版权.md`：图像、音乐、文字和语音来源。

## 复现

在本项目目录运行：

```powershell
python ..\存在主义项目\manju.py --script .\漫剧脚本.json --out .\output\乘风入山海.mp4
```

依赖沿用现有渲染器：Python、Pillow、NumPy、imageio、imageio-ffmpeg、pyttsx3。默认使用 Windows 离线中文语音，不需要上传参考视频或调用外部配音服务。项目内 BGM 的 SHA-256 为 `6E1DEA1929134F6195E5E549AA2A42DD14D01C56FC5C35EC94CFA32375969B87`。

正式交付包位于 `..\..\03_交付\乘风入山海_20260911\`。项目目录保留事实源和可复现配置，交付目录只保留最终成片与必要说明。
