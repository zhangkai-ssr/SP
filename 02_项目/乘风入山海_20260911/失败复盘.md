# 第一版本地样片失败复盘

## 用户验收结论

2026-09-11，用户确认第一版本地样片“效果太差，基本就是照片，不是视频”，并指出机械旁白不应加入。

## 根因

1. 渲染器只对静态插画做缩放和平移，没有角色动作、衣摆惯性、纸鹤振翅、雨雾变化、空间视差或镜头穿行。
2. 把参考片底部文字误判成需要朗读的口播，加入了 Windows 离线 TTS；参考类型实际更接近音乐短片。
3. 接触表只能证明构图和角色连续，不能证明时间维度中的动作质量。
4. 自动编码、黑帧、静音和响度检查通过，不等于创意与动态表现通过。

## 处理

- 撤回 `03_交付/乘风入山海_20260911`，不再把该版本称为正式成片。
- 本地失败样片仍保留在 Git 忽略的 `output/` 和 `work/`，用于后续 A/B 对照。
- 最终方向改为 Seedance 2.5 多模态图生视频：无旁白、无对白、无 TTS，要求人物、载具、环境和相机同时运动。
