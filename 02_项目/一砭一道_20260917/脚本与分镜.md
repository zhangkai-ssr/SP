# 《医馆里最有用的东西，是空的》测试脚本与分镜

## 故事事实源

- **一句话**：一个认为医馆里“满”才有价值的富商，嘲笑空罐；暴雨漏进医馆时，正是那只空罐接住雨水，保住桌上的旧账簿，他也学会为真正需要的东西留出位置。
- **经典落点**：《道德经》第十一章以器物的空处说明其用途；片中仅在结尾出现一次“当其无，有器之用”。采用[中国哲学书电子化计划《道德经》第十一章](https://ctext.org/dictionary.pl?id=11602&if=gb)的通行文字。现代解释只落在“器皿有形，能容纳的空间让它发挥作用”，不延伸成疗效、致富或其他承诺。
- **性质**：原创现代寓言，非《道德经》原有故事，也不描述老子生平。
- **规格**：约 48 秒，9:16 竖屏，8 镜头。它是流程样片；正式发布版仍按账号总方案评估 60–90 秒结构。
- **声音**：对白和古文在后期配音与叠字幕，豆包镜头不要求人物口型。雨、雷、陶罐接水、木箱和布料为主要拟音；配乐保持克制。

| 空罐与砭石 | 空罐为无字、无盖、带浅褐釉的宽口陶罐；黑色砭石作为旧账簿镇纸 | 罐形、大小、桌上位置连续；砭石只作器物符号，不接触人体 |
| 无名医馆 | 夜晚一间木质正厅；左侧药柜、中央桌案、右侧窗；屋顶漏点在桌案上方 | 镜头保持左右关系；雨水不会凭空从窗边变到屋顶 |

先制作三位人物的正面/侧面/半身参考、医馆建立图和陶罐近景。固定画风为写意二维国风漫画：可见线条、克制纹理、深青雨夜与暖黄烛灯；避免真人摄影、塑料 3D 和生成文字。后续每张分镜图、每段视频均引用已确认的资产描述。

| 镜头 / 时段 | 画面、行动与景别 | 豆包视频必须呈现的动作 | 后期台词/声音 |
| --- | --- | --- | --- |
| S01 / 0–4 秒 | 刚从雨中进门的富商仍披着湿外衣，指尖轻敲桌上的空陶罐；镜头从罐口抬到他疑惑的侧脸。 | 手指轻敲、陶罐微震、雨痕滑过右侧窗，摄影机小幅抬升。 | 富商：“空的，也摆在这儿？”陶罐清脆一响。 |
| S02 / 4–10 秒 | 左侧满柜药罐与中央唯一空罐形成反差。阿青站在桌边，想把一袋干草药倒入空罐。 | 阿青提起袋子、停住，袋口只到罐上方；不展示服用或功效。 | 富商：“装满了才值钱。”背景雨声。 |
| S03 / 10–15 秒 | 守一先生按住袋口，让阿青把草药袋放回左侧柜上；空罐仍在桌案中央。 | 两人的手分工清楚，袋子回柜，罐没有提前移动。 | 守一先生：“先留着。” |
| S04 / 15–20 秒 | 雷声后屋顶滴水加快，滴点正对旧账簿；黑色砭石压着账簿一角。阿青回头。 | 雨滴从梁下落，纸角浸湿，阿青转身；无突然换场。 | 雷声、第一滴水落在纸上的声音。 |
| S05 / 20–27 秒 | 阿青迅速将空罐推到滴点正下方，水连续落入罐中；守一先生把账簿移开。 | 手推动陶罐、陶罐停止、滴水准确落入罐中，账簿被移到干燥处。 | 水滴敲击陶罐；其余声音短暂变弱。 |
| S06 / 27–34 秒 | 富商低头看湿透的外衣，再看自己塞满器物的木箱；他尝试收起外衣，却放不进去。 | 打开木箱、尝试放入、停手；镜头能看清“已满”。 | 衣料摩擦、木箱轻响，无说教台词。 |
| S07 / 34–41 秒 | 富商取出几件无用装饰，给湿外衣留出空间；他抬头看向正在接雨的空罐。 | 装饰品被清楚移出、外衣放入、箱盖能合上，视线转向陶罐。 | 雨声渐缓；旁白可选：“有些用处，要先留出空处。” |
| S08 / 41–48 秒 | 空罐稳稳接住最后几滴雨，账簿被移到干处；守一先生与阿青继续收拾，富商轻轻扶正陶罐。镜头以仍在运动的雨光收尾。 | 水滴、手扶罐、衣袖和窗外雨光持续变化，不冻结成海报。 | 后期一次出现原文“当其无，有器之用”及出处“《道德经》第十一章”；另以小字标明传统文化故事、非诊疗建议。 |

## 三个助手的输出要求

1. **剧本助手**：只依据上表优化节奏和台词，输出仍是 S01–S08；不得把富商改成患者，不能增加治疗行为或另一个经典落点。
2. **静态分镜助手**：先输出固定角色/医馆/陶罐参考板，再输出 S01–S08 每镜的构图、人物位置、景别与首帧/末帧建议。重点检查医馆“左柜、中央桌、右窗”和漏点位置。
3. **动态镜头助手**：每镜输出一个主动作、环境反应、摄影机运动和与下一镜衔接的末帧。动作不可只写“人物动起来”；每镜不超过其时间段，也不靠模型生成可读文字。

## 豆包首轮测试顺序

1. **S01** 检查 3 秒钩子、陶罐造型及人物面部/手部；若敲罐穿模，改用手指停在罐沿、后期补敲击声。
2. **S05** 检查陶罐、滴水、手与账簿的因果动作；若同镜连续动作失败，拆为“推罐”与“接水”两个短镜，再在剪辑中衔接。
3. **S07** 检查木箱“满→腾空→放入外衣”的可读性；若多步动作失败，拆成物品移出与外衣放入两个镜头。

三个关键镜头通过后才补齐其余片段。豆包是否支持参考图、首尾帧及单次时长，执行时按界面核对；只上传经许可使用的自制参考资产。每个镜头保存完整提示词、模型/模式、任务 ID、生成时间、费用、候选文件与拒绝原因。

## 剪辑与验收

后期用实际选中的片段确定最终精确时长。古文、现代释义、对白和片名均在剪辑中加入并逐字校对；保留故事动作优先，不用长篇解释压过反转。手机端静音观看应能理解“空罐被嘲笑→接水护书→来客学会留空间”；带声观看检查对白、环境声和音乐层级。动态质量、人物与陶罐一致性、字幕安全区、编码、黑帧、静音、来源与授权均按总流程验收。未生成前不得写“样片通过”。
