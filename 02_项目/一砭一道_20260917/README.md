# 一砭一道｜《空药罐》流程测试

本目录是《一砭一道》首轮**内部制作测试**，采用账号选题表第 3 集“医馆里最有用的东西，是空的”。约 48 秒、9:16、8 镜头；当前视频生成工具为豆包。目标是验证从经典核对到脚本、角色参考、分镜图、动态镜头、声音和候选成片的完整链路。**尚未生成图像、视频、配音或成片，也未发布。**

## 为什么选它

仓库的 7 集选题目前只有梗概，没有可直接生产的单集脚本。第 1 集涉及砭石接触身体，首测会增加医疗审核与手部动作难度；第 2 集的巨石和水流需要较多环境与物理效果。第 3 集在同一间医馆内用“满罐/空罐”形成清楚的画面反差，能复用守一先生、阿青、来客和黑色砭石这些系列资产，也避开疗效叙事。此选择是**制作可行性判断**，不代表已经验证传播效果。
