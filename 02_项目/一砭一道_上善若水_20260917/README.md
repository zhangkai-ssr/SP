# 一砭一道｜《水为什么从不和石头争》测试方案

采用[`《一砭一道》首批选题第 2 集`](../../docs/一砭一道_AI短视频起号制作流程.md)的冲突，制作约 48 秒、9:16、8 镜头的原创内部测试片。当前视频生成工具为豆包。**本目录只有方案与待执行的测试记录，尚无图像、视频、声音或成片。**

- [`创作方案.md`](创作方案.md)：故事、经典依据、角色与场景锁定、逐镜时间线、验收标准。
- [`豆包首轮测试提示词.md`](豆包首轮测试提示词.md)：优先验证 S01、S05、S06 三个关键镜头的提示词和拆镜预案。
- [`测试记录.md`](测试记录.md)：执行状态与逐镜证据要求。

本片与[`空药罐测试`](../一砭一道_20260917/README.md)共用守一先生、阿青和黑色砭石的系列设定，但场景变为河谷与旱田。两片均属制作测试，不默认发布，也不把 AI 生成的水流画面当作真实水利工程建议。实际生成前按总流程确认参考资产、豆包界面能力和费用；本地素材上传或付费生成仍需明确授权。
