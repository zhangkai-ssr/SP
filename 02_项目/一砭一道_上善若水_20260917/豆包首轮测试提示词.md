# 豆包首轮测试提示词｜上善若水

以下文本是待测试输入，**尚未在豆包生成**。先用人工确认的地形俯视图固定水路：左侧上游 → 中央巨石 → 巨石右下方旧水道 → 右下旱田。如豆包当前入口不支持参考图，先用文字和连续关键帧检查方向；界面时长不匹配时生成较长片段后剪短。

## 共用画面约束

```text
原创二维国风漫画短片，9:16竖屏，暮夏清晨的河谷和旱田。画面左侧为浅水上游，中央为固定不动的灰黑巨石，右下方有一条被落枝堵住的低处旧水道，旧水道连向右下旱田。水只按左到右、由高向低的方向运动。守一先生约50岁，黑发夹少量银丝、深青外衫米色内衫；阿青约20岁，短黑发、灰蓝短褂；农人约40岁，深棕短褂和草帽。人物五官和衣着连续。没有爆破、洪水、神迹、诊疗动作、生成文字、logo或水印；对白与古文后期添加。
```

## S01：问题能否一眼看懂，目标 4 秒

```text
镜头先给右下方干裂田埂的短暂近景，迅速沿干涸水道反向看到中央灰黑巨石挡住左侧来水。农人站在石头与田之间，抬手指向巨石，脸上急切。左侧浅水在石前回旋，右下旱田依旧干燥，左右和高低关系清楚。摄影机小幅从田埂向石头推进。画面不出现炸药或任何爆破准备，人物不说话，字幕后期加。
```

通过条件：静音观看能看懂“有水、石头、缺水的田”；石、水和田的方位稳定。若 4 秒空间关系不清楚，拆为田埂与石前两个镜头。

## S05：疏通动作有没有因果，目标 7 秒

```text
在同一块灰黑巨石的右下方，旧水道入口被几根落枝堵住，左侧有少量浅水积在入口外。农人与阿青用手或木耙把落枝向外清开，清开后才有一股细水进入原有低处水道。先近景看枝条被移走，再顺水轻轻右移；巨石始终不动，水量逐步增加但不成为洪水。手、木耙、枝条和水各自位置连续，不出现新增人物或凭空出现的水。
```

通过条件：清障在前、水流改变在后。若手/枝/水同时变形，拆为“清开枝条”和“水入旧道”两个片段。

## S06：水是否连续绕石，目标 7 秒

```text
从巨石右下方已经打开的旧水道入口开始，摄影机低机位顺着一股细水向右下方跟拍。水沿地面浅沟绕过巨石外侧，平缓下行，远处逐渐出现干燥田地；画面中始终能看出水从同一上游而来，没有穿过石头，没有突然切换到另一条河。保持写意二维国风漫画质感，真实流动和地形视差，不是静态图片平移或凭空出现的瀑布。
```

通过条件：水流方向、绕石路径与地形草图一致，镜头有可见连续流动。若一次生成无法维持路径，拆为“石旁弯道”和“田前水道”两段，并用同一参考末帧衔接。

执行后把实际模型/模式、目标与实际秒数、提示词变更、参考图、任务 ID、费用、候选文件和拒绝原因填入[`测试记录.md`](测试记录.md)。三个关键镜头合格后再补齐其余五镜；单镜美观不能代替故事和连续性验收。
