# 制作说明

## 创作定位

本片是约 40 秒的原创横屏国风动画短片。参考片只用于抽象“人物亮相—出发—受阻—领悟—突破”的节奏结构；主角、纸鹤、场景、旁白和标题均重新设计。

## 制作流程

1. 用 ffprobe、定时取帧和场景差异扫描分析参考片规格与节奏。
2. 使用 OpenAI ImageGen 生成 6 张同一原创角色的 16:9 国风插画。
3. 复用仓库现有 `02_项目/存在主义项目/manju.py`，完成离线中文旁白、字幕、标题卡和 Ken Burns 运镜。
4. 混入仓库内程序化生成的原创 `ambient.wav`。
5. 以 H.264 CRF 20、AAC 192 kbps、44.1 kHz 重新压制，并规范响度与 MP4 快速启动信息。

项目事实源位于 `02_项目/乘风入山海_20260911`。项目内可使用以下命令重新渲染：

```powershell
python ..\存在主义项目\manju.py --script .\漫剧脚本.json --out .\output\乘风入山海.mp4
```

最终压制使用 FFmpeg `libx264`、`-crf 20`、`yuv420p`、AAC 192 kbps、44.1 kHz，并应用 `loudnorm=I=-16:LRA=11:TP=-1.5`。

## 能力边界

本片使用静态原创插画配合数字运镜，并非逐帧角色动画或文生视频模型生成的连续动作。适合作为同类型叙事样片；若需要衣摆、纸鹤翅膀、雨水和表情连续运动，可将六个镜头提示词与首帧继续交给 Seedance 2.5 做图生视频升级。
