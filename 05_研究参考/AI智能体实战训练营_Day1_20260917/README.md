## 可复用的核心方法

Day1 主张先由人完整走通一次 **脚本 → 分镜图 → 分镜视频 → 剪辑与声音 → 成片**，再考虑将步骤连接成自动化流程。这样才能知道每一步的输入、产物和失败原因。笔记把三个“智能体”分别用于剧本结构、静态分镜提示词、动态镜头提示词；这里的“智能体”更接近带有固定步骤和输出格式的专用助手，不能仅凭名称认定它已经具备自主执行或稳定交付能力。

| 阶段 | 输入 | 应交付的可检查结果 | 人工确认点 |
| --- | --- | --- | --- |
| 故事与脚本 | 题材、受众、时长、人物、情绪 | 主题、冲突、转折、结尾和逐镜头动作 | 开头是否抓人、结局是否清楚、能否拍出 |
| 角色与分镜图 | 脚本、角色设定、画风 | 角色参考图与逐镜头关键帧 | 五官、服装、道具、场景和镜头方向是否一致 |
| 动态镜头 | 关键帧、动作、机位和节奏 | 逐镜头视频片段 | 人物、环境、摄影机是否真的在运动；动作是否连贯 |
| 剪辑与声音 | 合格片段、旁白/音效/音乐 | 候选成片 | 节奏、字幕、声画、版权和导出参数 |

## 从笔记提炼的操作原则

1. 先做 30–60 秒、约 6–10 镜头的完整样片，再扩大时长。此为练习规模，不是平台“爆款”保证。
2. 写需求时明确目标、输入、步骤、验收标准和输出格式。提示词长度本身不是质量标准。
3. 先锁定角色正面、侧面、半身、全身和关键道具，再生成镜头；人物一致性需要逐镜头检查，参考图不能保证自动一致。
4. 动态提示词写清主体动作、动作速度、摄影机、环境反应和镜头衔接；静止图推拉不能冒充动态视频。
5. 逐镜头保留所用工具、模型版本、输入、候选、人工选择理由及失败样本，便于复现和决定以后自动化哪些环节。
6. “输入主题后一键成片”与“百倍提效”是课程对后续自动化的目标或宣传表达；是否成立要以实际耗时、费用、重试次数和成片质量对比验证。
