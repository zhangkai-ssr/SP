# 《水为什么从不和石头争》创作方案

## 故事与经典

- **一句话故事**：一位农人见巨石挡住来水，想把石头炸开；阿青和守一先生发现一条被树枝堵住的低处旧水道，农人清开堵塞，让水绕过巨石流进旱田。
- **改编边界**：仓库原选题的“要炸掉巨石”保留为人物的冲动提议；片中不出现炸药、布置、引爆或操作示范。解决问题的行动是清开旧水道入口，巨石始终留在原处。
- **经典落点**：取《道德经》第八章“水善利万物而不争”。[中国哲学书电子化计划的第八章原文](https://ctext.org/dictionary.pl?id=11599&if=gb)同时写到水“处众人之所恶”；本片通过水往低处流、到达禾苗来表现“不争”和“利物”。“水绕开石头”是原创情节，不冒充原文原句或水利技术论证。
- **形式**：约 48 秒、8 镜头、9:16 竖屏的写意二维国风漫画短片。正式发布版仍需按系列标准评估 60–90 秒完整叙事。
- **情绪线**：冲动对抗 → 看见被忽略的低处 → 小行动引水 → 旱田受益。开头 3 秒直接让观众看见巨石和干田之间的水流中断。
- **声音**：对白与经典原文后期加入，不依赖口型生成；主要声音是浅水、木枝、脚步、风与禾苗。音乐在水到达旱田时才抬起。

## 固定人物与空间

| 元素 | 锁定要求 |
| --- | --- |
| 守一先生与阿青 | 沿用[`空药罐项目`](../一砭一道_20260917/脚本与分镜.md)的人物外貌和衣着；外出时仅加同色斗笠，不换脸换装。守一先生不讲长篇道理，阿青先观察、后协助。 |
| 农人 | 约 40 岁，深棕短褂、草帽、粗布裤；不增加围观人群。 |
| 黑色砭石 | 只压住河岸上的简易水道图纸，形成系列视觉识别；不接触人体，不作为神奇工具。 |
| 地形 | 画面左侧为上游，中央为灰黑巨石，右下方是通往旱田的低处旧水道；入口被几根落枝堵住。水从左向右、由高向低流，田在右下方。 |
| 风格 | 暮夏清晨，浅赭色旱田、青灰石、清透水色；可见漫画线条和真实水体方向，避免洪灾、巨浪或凭空出现的水。 |

先做一张地形俯视草图，再做三位人物和巨石/水道参考图。所有分镜都依此保持左右方向；如果静态分镜说不清水从哪里来、往哪里去，先改地形，不进入视频生成。

## 48 秒逐镜时间线

| 镜头 / 时间 | 画面与动作 | 必须看见的运动和因果 | 后期声音/字幕 |
| --- | --- | --- | --- |
| S01 / 0–4 秒 | 从干裂田埂快速切到挡在水前的巨石。农人指向石头，面向阿青。 | 左侧水碰到巨石后停滞/回旋，右下田埂仍干，农人手指方向明确。 | 农人：“炸开它，水才能过来？”仅作为冲突台词，不示范爆破。 |
| S02 / 4–10 秒 | 守一先生、阿青沿河岸走近；黑色砭石压着一张简易水道图。 | 走动、衣摆和浅水流持续；镜头交代左上游、中央石、右下田。 | 浅水声与脚步，无解释性长对白。 |
| S03 / 10–16 秒 | 阿青蹲下，看见巨石右下方一缕水迹；镜头沿水迹找到被落枝堵住的旧水道入口。 | 阿青视线→水迹→落枝按顺序出现，水迹不从石头内部冒出。 | 阿青：“那边的低处，原来有条旧水道。” |
| S04 / 16–21 秒 | 守一先生让开位置，农人放下准备敲石的工具，走向旧水道。 | 工具放地、农人转身走动；石头保持原状。 | 工具落地声；守一先生只说：“先看看水往哪儿走。” |
| S05 / 21–28 秒 | 农人与阿青用手或木耙清开入口处几根落枝；细水开始进入旧水道。 | 落枝移开后水才改变方向；手、木耙、枝和水不能穿模或瞬移。 | 落枝摩擦和第一股水流声。 |
| S06 / 28–35 秒 | 摄影机沿低处水道跟随细水绕过巨石，向右下方旱田流去。 | 从左到右连续可见的水流、绕石弧线和下降坡度；不变成突然出现的洪水。 | 水声逐渐清亮，音乐轻入。 |
| S07 / 35–42 秒 | 水抵达田边，浸润一排干土；农人放下手中的工具，阿青望向田地。 | 土壤由干转湿、禾苗轻摆；不夸张成瞬间长成成熟庄稼。 | 农人轻声：“石头没动，水却到了。” |
| S08 / 42–48 秒 | 远景中巨石还在，细水从旁边低处绕行，田边三人静静看着；镜头顺水前移结束。 | 水、禾苗、衣摆与摄影机持续运动，不冻结成海报。 | 后期只出现一次“水善利万物而不争”及“《道德经》第八章”；小字说明为传统文化故事，非诊疗或水利操作建议。 |

## Day1 流程落到本片

1. **剧本检查**：先确认 S01 的问题、S03 的发现、S05 的行动、S07 的结果在静音下都能看懂；原文和现代解释分别标注，不让守一先生直接讲完整篇道理。
2. **角色与静态分镜**：锁定共用人物参考；另做河谷地形图、巨石、旧水道入口、旱田四项视觉基准。先审 S01–S08 的首帧/末帧和水流方向。若左右关系不一致，重新排镜。
3. **动态镜头提示词**：每镜说明主体动作、环境变化、摄影机路径、镜头结束姿态。豆包优先测试 S01 的空间、S05 的疏通因果、S06 的连续水流；若生成失败，按[`首轮提示词`](豆包首轮测试提示词.md)拆镜。
4. **逐镜生成与后期**：按当日豆包界面可用的模式生成，不预设参考图、多帧、时长或收费一定可用。仅用许可清楚的自制素材；保存每次候选和失败原因。剪辑时配对白、环境音、音乐与准确的古文字幕，再用手机比例完整观看。

## 测试重点与验收

- **故事**：从“想破石”转为“看见低处旧道”，主角通过清障而非一句道理改变结果；最后一镜体现水到田地、惠及作物。
- **空间**：上游始终在左，石在中，田在右下；S03 的旧道入口与 S05 疏通位置一致，S06 水流不跳切穿石。
- **真实运动**：水流、手移枝、人物步伐和植物响应都可见；不能用一张静态画推拉代替水的连续运动。
- **边界**：无爆破细节、医疗疗效或未经证实的工程效果声明；古文经人工核对，模型不直接绘制字幕。
- **技术与来源**：按总流程检查画幅、编码、音轨、黑帧、静音、字幕安全区、素材许可及模型/提示词/费用记录。完成文本方案不等于豆包视频或成片验收通过。
