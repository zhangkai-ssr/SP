当前阶段：4分33秒内部试剪，1080×1920、30fps、H.264/AAC。画面取自第三方上传的《天道》剪辑，保留来源标识和烧录字幕；关闭其全部音轨，使用原创解说与本地合成氛围音垫。已避开128—185秒及248秒以后的解读密集区间；其余来源字幕也可能含上传者解读，未逐帧确认其为原剧字幕，未冒充官方净片。原剧与上传者的发布使用授权尚未核实，不自动发布。

## 恢复制作

Windows、Python 3.12、FFmpeg（含libass/libx264）、微软雅黑字体。项目级环境安装requirements.txt。旁白使用edge-tts 7.3.1、zh-CN-YunxiNeural、语速-5%，需要联网但不配置API Key；外部服务可用性可能变化。

1. 按素材来源.md恢复同一输入为assets/source/退租候选.mp4，并核对本地SHA-256；不使用其他版本直接套用秒数。
2. 在本目录运行：python 生成旁白.py。读取旁白稿.json，生成audio/旁白_初稿.mp3、旁白时间线.json和output/字幕_初稿.srt。
3. 运行：python 制作样片.py。读取旁白时间线.json，生成storyboard.json，重新渲染全部15段并混音，输出output/肖亚文退租_原剧解说_内部试剪.mp4。不会按旧分段文件大小跳过渲染。

旁白时间线.json保存本次实际时间点；生成旁白.py每次重新合成全部旁白，不复用旧语音缓存。重新合成语音后时间点可能变化，必须重新制作整片并复核。生成过程文件和媒体均忽略，不依赖个人机器的绝对路径。最终听感与平台效果待用户验证，未制作或测试剪映草稿。
