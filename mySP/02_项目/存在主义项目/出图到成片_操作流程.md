# 在线出图 → 自动成片 操作流程

> 适用于本机（无独立显卡）：**画面用在线平台出，本机只负责拼接成片**。
> 配套脚本：`manju.py`（漫剧渲染器）、`漫剧脚本.json`（分镜）。

---

## 总览

```
①在线出图(即梦/Liblib)  →  ②命名 01~10.png 放进 assets\manju\
        ↓
③(可选)改 漫剧脚本.json 台词/运镜
        ↓
④ python manju.py   →  output\存在主义短片.mp4（带配音+字幕+运镜）
        ↓
⑤(可选)拖进剪映精修：换更自然的配音、加BGM/音效、调色、加片头片尾
```

---

## ① 在线出图

### 推荐平台
- **即梦 AI**（jimeng.jianying.com，字节，和剪映同生态，**首选**）：文生图 + 图生视频，漫剧工作流成熟。
- **LiblibAI**（liblib.art）：漫剧/动漫风工作流模板多，可控性强。

### 关键设置
- **比例**：选 **9:16**（竖屏），分辨率尽量高（1080×1920 或更高）。
- **风格统一**：10 张图用**同一个风格词 + 同一主角设定**，否则画面会跳。建议固定一句风格前缀（见下），每张只改场景。
- **主角一致性**：如果出现人物，用平台的"角色参考/同人物"功能锁定同一张脸；本项目用的是**剪影/背影**，一致性压力小。

### 统一风格前缀（每条 prompt 前都加）
```
电影感，极简主义，孤独人物剪影，低饱和冷暖对比，胶片颗粒，
大量留白，竖构图 9:16，氛围光，景深虚化，安静、克制、哲思氛围 --ar 9:16
```

### 10 个分镜 prompt（对应 01~10.png）

## ② 命名并放置

把出好的图**改名成 `01.png` ~ `10.png`**（必须两位数、png 格式），放进：
```
存在主义项目\assets\manju\
```
直接覆盖原来的占位图即可。**文件名要和 `漫剧脚本.json` 里每个镜头的 `"image"` 字段对应。**

### 用动态视频片段（即梦/可灵 图生视频的产物）
`manju.py` 已支持**视频片段当镜头背景**。把镜头的字段从 `"image"` 换成 `"clip"`，填视频文件名即可：
```json
{"clip": "06.mp4", "speaker": "哲人", "text": "加缪望着\n推石上山的西西弗斯"}
```
- 支持 `.mp4 / .mov / .webm / .mkv / .avi / .m4v`，放进 `assets\manju\`。
- clip **比镜头短会自动循环**，比镜头长只取所需部分；画面自动裁成 9:16 铺满。
- 视频镜头不再加 Ken Burns（片段本身有动态）；静图镜头继续走运镜。
- 同一条片子里**静图镜头和视频镜头可以混用**。

#### clip + image 回退（推荐写法）
一个镜头可以**同时写 `clip` 和 `image`**：
```json
{"clip": "06.mp4", "image": "06.png", "speaker": "哲人", "text": "..."}
```
- `06.mp4` 在 `assets\manju\` 里 → 用视频；
- 还没出视频 / 文件缺失 → **自动回退用 `06.png` 占位图**出片（日志标 `[占位待clip]`）。

这样可以**先把所有镜头排好版正常出片**，等即梦的动态片段陆续出好，丢进文件夹就自动替换，无需改配置。当前 `漫剧脚本.json` 已对镜头 1(`01.mp4`)、7(`06.mp4`)、11(`10.mp4`) 预设了这种写法。

## ③ （可选）改剧本

打开 `漫剧脚本.json`：
- 改 `scenes[].text`：台词（用 `\n` 手动分行，每行≤12字最稳）。
- 改 `scenes[].motion`：运镜，可选 `zoom_in` / `zoom_out` / `pan_left` / `pan_right` / `static`。
- 改 `scenes[].image`：该镜头用哪张图。
- 改 `scenes[].speaker`：`旁白` / `内心` / `哲人`（对应不同声线与字幕颜色）。

---

## ④ 生成成片

在**本文件夹内**打开 PowerShell：
```powershell
python manju.py --out output\存在主义短片.mp4
```
- 配音默认离线 `Huihui`（机械但免联网）。
- 挂了代理后想要自然配音：把 `漫剧脚本.json` 的 `"engine"` 改成 `"edge"`，再跑一次。
- 加背景音乐：把音乐文件路径填进 `漫剧脚本.json` 的 `"bgm"`。

---

## ⑤ （可选）剪映精修

把 `output\存在主义短片.mp4` 拖进**剪映专业版**，可以：
- 用剪映的 **AI 配音**换更自然的旁白（替换掉离线音）；
- 加 **背景音乐 / 音效 / 转场**；
- **调色**统一冷暖、加片头片尾、加封面标题。

---

## 常见问题
- **画面跳/不统一** → 10 张图没用同一风格前缀，重出。
- **字幕被画面盖住看不清** → 出图时让**底部留暗/留白**，字幕在底部 1/4。
- **配音难听** → 离线音的局限，挂代理换 edge-tts，或直接在剪映里用 AI 配音。
- **想换主角真人/动漫脸** → 在即梦用"角色参考"锁定同一形象再出 10 张。
