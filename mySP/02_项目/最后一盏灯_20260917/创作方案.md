# 《最后一盏灯》创作方案

## 作品定位

- **形式**：45 秒、9:16 竖屏、原创二维漫画电影风格短片；7 个镜头。面向短视频平台的故事小样，不作为已确认的正式交付。
- **一句话故事**：暴雨使整条街熄灯，一位夜行者几次护住将灭的灯；当它终于亮起，街上其他窗户也依次亮了。
- **情绪线**：异常/悬念 → 受阻 → 坚持 → 回应/温暖。前 3 秒让观众看见“整条街黑了，只剩一盏灯”。
- **视觉规则**：冷蓝雨夜与暖琥珀灯光对比；固定一位成年主角、一盏铜框玻璃提灯和同一条街，避免新增角色与复杂地点。所有可读文字、标题和字幕在后期添加，不交给视频模型绘制。
- **角色锁定**：成年夜行者，短黑发、深蓝雨衣、黄色围巾、黑色挎包；脸、服装和身高比例保持不变。提灯为六角铜框、透明玻璃、单一暖黄火焰。
- **声音**：无角色对白或口型；雨、风、火苗、脚步和街道环境声。可用三句简短中文旁白辅助叙事，最终是否保留以样片听感决定。音乐须有可记录的使用权。

## 45 秒镜头表

| 镜头/时间 | 画面与叙事 | 必须出现的真实运动 | 后期声音/文字 |
| --- | --- | --- | --- |
| 1 / 0–4 秒 | 全街灯光同时熄灭；雨幕中唯有檐下一盏微弱提灯。近景灯火切到街道大全景。 | 灯火摇晃、雨水斜落、摄影机从灯后移出。 | 远雷与骤然消失的电流声；字幕“整条街，突然黑了”。 |
| 2 / 4–10 秒 | 夜行者从街角跑来，看见提灯，伸手将它从风口移开。 | 奔跑、停步、手与提灯接触，雨衣和围巾随惯性摆动。 | 脚步、急促雨声。 |
| 3 / 10–16 秒 | 一阵风吹开雨衣，火苗几乎熄灭；主角回身遮挡。 | 火苗缩小、衣摆被风掀起、主角移动重心。 | 风声增强；旁白候选：“黑下来的时候，总得有人护住一点光。” |
| 4 / 16–23 秒 | 主角用身体和雨衣遮住提灯，火苗重新稳定。特写手、玻璃上的雨滴和主角神情。 | 雨滴沿玻璃下滑，手调整遮挡位置，火焰逐渐变亮。 | 风雨转弱，听见火焰轻响。 |
| 5 / 23–30 秒 | 主角提灯穿过黑暗街道；暖光照到湿石板和连续的店铺。 | 自然行走、灯摆动、脚下水波、侧后方跟拍。 | 脚步与水声；旁白候选：“一盏灯，先照亮一步。” |
| 6 / 30–38 秒 | 沿街窗户由近到远依次亮起，主角停下回头。 | 窗光按空间顺序点亮，雨滴与倒影响应，摄影机抬升。 | 环境声渐暖，音乐进入高潮。 |
| 7 / 38–45 秒 | 主角站在仍下着细雨的街头，提灯与远处窗光呼应；镜头越过肩膀看见明亮街道，连续运动收尾。 | 主角呼吸、围巾摆动、雨水和灯影持续变化，摄影机缓缓前行。 | 旁白候选：“原来，光会被传下去。”；片名后期叠加。 |

## 按 Day1 方法执行

1. **剧本助手**：把本方案交给文本模型，只允许优化 45 秒节奏、旁白和动作可拍性；输出仍为 7 行镜头表。人工确认故事逻辑后锁稿，不让每个模型重新改写剧情。
2. **分镜图像助手**：先生成一张角色参考板（正面、侧面、半身、全身）和一张提灯参考板；再为每个镜头写静态关键帧提示词。每条提示词固定角色、服装、灯形、画风与冷暖色，再补场景、景别、机位。逐张检查后才进入视频阶段。
3. **分镜视频助手**：依据已选关键帧，为每镜只写该镜头的主体动作、环境反应、机位运动和收尾姿态。视频目前使用**豆包**生成；优先利用实际界面提供的参考图或首尾帧功能，若当前版本没有这些功能，则用固定角色设定与上一镜末帧人工校对，不假定某项功能必然可用。
4. **逐镜生成与复核**：先做镜头 1、3、6，确认雨、火焰、窗光和人物动作能表达故事，再生成其余镜头。每镜只选一条合格片段；失败样本和重试原因保存在 `work/`。如果需要多帧转场，仅在界面支持且叙事需要时使用，不为了展示功能添加无意义变身。
5. **后期合成**：在剪映中按表剪辑，补环境声、已确认可用的音乐、旁白候选与中文字幕。检查字幕安全区和手机端可读性；导出后再看完整成片，避免只看单镜效果。

### 给各阶段助手的共同输入格式

```text
目标：完成《最后一盏灯》45 秒竖屏原创短片的【剧本/分镜图/动态镜头】阶段。
事实源：本创作方案中已锁定的故事、角色、提灯、7 镜头时间线和视觉规则。
约束：不增加人物，不改写结局，不生成可读文字，不借用已有影视角色或课件画面。
输出：按镜头编号给出输入素材、提示词、预期动作、与前后镜头的衔接、易错点。
自检：指出人物或道具漂移、缺少真实运动、时长超限、叙事不清的风险。
```

## 素材、费用和授权记录

实际制作时逐镜记录：日期、豆包界面所示模型/模式、比例与时长、所用参考图、完整提示词、候选文件名、重试次数、选择原因及是否产生费用。图像、音乐、音效、字体和旁白分别记录来源与许可。将本地参考图或音频上传到豆包等外部服务，以及触发付费生成，须先取得相应授权；本方案本身不构成上传或付费授权。

## 验收与下一步

- **叙事**：不开声音也能看懂“熄灯—护灯—亮灯—回应”；开头 3 秒有明确异常，结尾有回应。
- **动态**：每镜至少看得到主体或环境的实际变化；不能用静态图推拉替代奔跑、挡雨、雨滴或灯光传播。
- **连续性**：主角脸、衣着、提灯造型不漂移；灯始终在同一只手或有清楚的换手动作；镜头方向和空间位置连贯。
- **技术**：片长约 45 秒、竖屏、画面无模型生成的乱码和水印；声音无突跳，字幕无越界。导出后再用实际文件检查分辨率、帧率、音轨、黑帧和静音。
- **决策**：记录总耗时、生成费用、重试次数和人工修正点，再决定哪些步骤值得在后续用智能体自动化。当前仅完成方案，尚未验证豆包生成、剪映兼容或成片质量。
