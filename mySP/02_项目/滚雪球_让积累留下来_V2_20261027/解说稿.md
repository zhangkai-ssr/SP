# 《滚雪球》：让积累留下来 · V2

原创虚构寓言。以复利的“保留基础，再继续积累”作为学习类比，不是收益公式或原书故事复述。

这块怀表，阿澈已经修好了三次。可今晚，秒针又停了。

桌上堆着拆下的零件，窗外的灯一盏盏灭了。他却连问题出在哪儿，都说不清。

过去一个月，他每天都很忙：拆开，换件，装回去。第二天再遇到故障，又从第一步开始。

他以为自己练了一个月。其实，只是把同一天，重复了很多遍。

《滚雪球》里，有一个很朴素的比喻：找到湿雪，再找一段长坡。雪球带着已有的雪，继续往前。

钱能这样积累，经验却不会自动如此。要把这个思路用在生活里，阿澈得先留住今天学会的东西。

他没有再写“今天修表五小时”。而是记下：平放能走，竖起来就停。换了发条，还是一样。

第二天，他只盯着这一处。先不换零件，把怀表慢慢立起来。秒针果然停在同一个位置。

他去请教老师傅，又回来对照着查。原来一处磨损，藏在他每次都跳过的检查里。

处理完磨损，他没急着合上表盖。平着放，竖着放，再试。那根秒针，这次一直在走。

阿澈在那页纸后面补了一句：遇到位置变化才出现的故障，先比较不同姿态，别急着换件。

一周后，另一块表送进来。外壳不同，毛病也没说清。他这次没有立刻拿起螺丝刀。

他先问：什么时候停？换个方向还停吗？答案不完全一样，但旧记录帮他缩小了检查范围。

留下来的，不是一句万能答案，而是一套少走弯路的检查方法。昨天的错误，终于帮上了今天的忙。

可就在这时，街对面的新工具亮了起来。别人说，有了它，什么都能修。阿澈差点把旧本子扔进抽屉。

他停了一下：这件工具，解决的是我现在遇到的问题吗？还是只让我觉得，自己又有了一个新开始？

他留下需要的工具，继续练最常遇到的故障。不是永远不换方向，而是先看见反馈，再决定下一步。

你的雪球，也许是一道终于讲明白的错题，一段改到能用的代码，或一次认真复盘的客户沟通。

学完之后，留下一份能重新使用的东西。下一次遇到相似的问题，先把它拿出来，而不是再搜一遍。

后来，阿澈也有没力气的时候。那晚，他关了灯，早早睡了。本子就在桌上，没因为休息而消失。

再回来，他翻到上次那页，接着查。真正要守住的，不是永不断掉的打卡，而是回来时还有路可走。

冬天快结束时，工坊还是那间工坊。阿澈没有突然变成大师，只是不再每次都被同一种错误困住。

他推开门，滚起一个小雪球。这回他懂了：走得久很重要，但每走一步，也要有东西留下来。

今天别急着改变整个人生。选一件事，做一次，看看结果，再把有用的部分留下。明天，从这里接着走。
