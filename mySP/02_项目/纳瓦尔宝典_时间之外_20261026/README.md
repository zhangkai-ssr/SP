# 《纳瓦尔宝典》· 把时间拿回来

原创横屏像素讲书短片。以虚构修表匠阿澈的故事，解释专长、可复制作品、长期积累与时间选择。

## 已确定的制作方向

- 用户要求：参照一只索尔的《纳瓦尔宝典》创作类似视频。
- 参考：[一只索尔《纳瓦尔宝典》财富篇](https://www.douyin.com/video/7692781833264845971)，实际页面播放器约5:08；另有[幸福篇](https://www.douyin.com/video/7693061796231441899)，本片选择财富主题。
- 沿用的表达形式：横屏、像素人物、游戏式章节和可视化道具。文案、虚构故事、人物、场景和音乐重新创作；参考视频不进入新成片。
- 本地制作规格：1280×720、24 fps、H.264/AAC、普通话合成旁白；26镜头、四章。最终参数以质检记录为准。
- 此系列后续封面默认竖屏，当前采用`assets/douyin_cover.png`；用户提供的主页截图显示竖版的标题与人物更完整。横版保留为历史参考。
- 不包含上传发布、付费云视频生成、声音克隆和剪映草稿。

## 本次运行环境

渲染使用本机 Python 3.12、Pillow 12.2、NumPy 2.4.4；FFmpeg来自本机已安装版本。旁白使用已有独立语音环境中的 edge-tts 7.3.1，没有更新系统Python依赖。`test_render.py`的缓存检查也需要edge-tts能被导入；实际视频渲染只依赖已有音频，不需要调用语音服务。

普通渲染入口：

```powershell
python test_render.py
python render.py --preview
python render.py
```

前提：已有 `work/audio_timing.json`、其中引用的分段WAV、两张美术资产、Pillow/NumPy、FFmpeg与微软雅黑字体。入口会创建自身需要的目录。重新生成旁白需在安装 edge-tts 7.3.1 的环境运行 `prepare_audio.py`，并可访问其语音服务；缓存文件名包含文案、声音、语速和工具版本的摘要，渲染时还会核对时间信息关联的文案与声音设置，失配就明确停止。脚本不读取或保存账号密钥。

## 下载与离线恢复

视频和工程包见[GitHub Release](https://github.com/zhangkai-ssr/SP/releases/tag/naval-time-20261026-v1)，确切文件及校验值见`交付清单.json`。

- `naval-time-film.mp4`：本地候选片。
- `naval-time-project.zip`：项目源码、美术、字幕、26段旁白WAV和时间信息。解压后从项目目录运行上述渲染入口；已有WAV时不需要重新请求语音服务。
- `naval-time-social-assets.zip`：头像、当前竖版封面、保留横版、发布文案与生成记录。

依赖可按`requirements.txt`配置；FFmpeg与Windows微软雅黑字体需要本机可用。Git普通检出不带被忽略的语音缓存，应先恢复工程包，或在语音环境运行`python prepare_audio.py`。

## 边界

字幕以服务返回的句子时间为基础，长句在标点处分段后按字数分配句内时间；没有进行逐字强制对齐。美术是AI生成的静态背景与角色姿势表，由本地脚本组成图层动画；不声称是生成式视频或完整骨骼动画。当前输出为待用户审看的本地候选片。
