# 制作说明

## 成片定位

- 题目：AI 最危险的，不是答错
- 形式：9:16 竖屏知识叙事短片
- 目标观众：日常使用生成式 AI 的职场人、学生、创作者
- 时长：87.9 秒
- 核心结构：反直觉钩子 → 效率收益 → 能力边界反转 → 批判性思考证据 → 三问行动法

## 制作配置

- 画面：7 张统一风格 AI 生成关键帧，使用 Ken Burns 缩放和平移形成镜头运动。
- 配音：Microsoft Edge 中文神经语音 zh-CN-YunyangNeural。
- 字幕：烧录字幕，并另附标准 SRT。
- 音乐：项目内程序化生成的 ambient.wav，循环混入。
- 音效：开场低频、风险转折和三问提示均为本地合成声音。
- 输出：H.264 + AAC、1080×1920、30 fps、约 27 MB，启用 faststart。
- 响度：综合约 -16.5 LUFS，真峰值约 -1.2 dBFS。

## 质量检查

- 已确认视频流与双声道音频流存在。
- 自动检测未发现持续 0.5 秒以上的黑帧。
- 自动检测未发现低于 -45 dB 且持续 1.2 秒以上的异常静音。
- 代表帧接触表人工检查：字幕未越界，底部安全区一致，标题与数据清晰可读。
- 逐场景时间由实际旁白音频长度生成，字幕与配音同源，因此没有独立字幕漂移。

## Runway 状态

Runway 已连接，但当前工作区是免费方案、没有视频生成额度，因此本版没有使用 Runway 动态片段。全部画面采用新生成静图加本地运镜完成，不影响交付与发布。若后续升级，可优先把能力边界、裂缝和三问三个镜头替换为 5–8 秒动态片段。

## 复现方式

在本目录运行：

```powershell
python .\manju.py --script .\storyboard.json --out .\output\重新渲染.mp4
```

重新渲染会生成配音、字幕和基础混音；最终成片还包含本次单独加入的提示音与响度归一化处理。
