## 成片能直接看到什么

### 文案：用具体人物承载书中观点

《从0到1》的公开简介以大疆创业经历串起主题；页面存在序章、四个论点章节和终章。它把观众带入一个具体问题，再逐段解释观点。开头和结尾之间设置问题，给继续观看的理由。

《富爸爸穷爸爸》的公开简介以泰森收入和破产的反差引出资产与负债，再用购买选择引导观众讨论。这里描述的是视频的表达方式，没有对其历史、财务数字逐项核实。

### 视觉：让概念变成游戏里的东西

- 同一讲述人物反复出现，像素桌面、电视、书本形成固定讲述空间。
- 人物头像、生命次数、进度条和道具承担信息提示；这些是画面内设计。
- 场景会从讲述桌面切换到夜间道路、办公室等，与内容推进对应。
- 第二支视频用拳台和人物状态栏呈现案例；抽象的财富概念有了可视化入口。
- 画面下方用大号白字、深色描边，部分词用黄色强调；上方保留章节导航。

这些截图只能证明成片视觉效果。无法从合成结果反推人物究竟是逐帧绘制、骨骼动画、剪辑关键帧还是生成式视频。

## 在 SP 中怎样复现：建议方案，不代表作者实际工具

1. **先写一条故事线。**只解释一个核心问题，用一个人物或事件串起来；整理事实来源，再分成开场、三段推进和收尾。
2. **先定旁白节奏。**录制或合成原创旁白，听完修改，再按停顿拆镜头。不要先堆满画面再强塞文案。
3. **建立小型像素素材包。**一个原创主持角色、少量表情和姿势、三处背景、若干道具即可。统一像素尺寸、配色和轮廓；放大时采用最近邻，避免边缘变糊。
4. **素材分层。**背景、角色、道具、数据、字幕分开；角色入场、位置变化、表情切换、数字变化和镜头推进分别控制。复杂动作再补短循环帧。
5. **先做30—60秒样片。**可用熟悉的剪辑工具完成图层与关键帧；SP负责旁白、字幕与导出辅助。确认风格和观看节奏后，再扩成完整讲书片。
6. **验证实际输出。**检查角色一致性、文字可读性、旁白与字幕同步、画面节奏、音量、素材来源和导出参数。后续平台效果需真实发布数据另行验证。

像素图可以人工绘制，也可以先生成再修整；两条路都可行。本次没有触发付费生成、声音克隆、素材上传或平台发布。
